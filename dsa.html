📦 Arrays — The Foundation
An array is a contiguous block of memory holding elements of the same type. In CineBook, arrays store the list of movies, theatres, showtimes, and seat rows. Arrays support O(1) random access by index — the most fundamental data structure.
// CineBook uses arrays extensively: const MOVIES = [movie1, movie2, movie3]; // movie catalogue const THEATRES = [theatre1, ... theatre5]; // all 5 theatres const seatRow = [seat1, seat2, ... seatN]; // per-row seats // O(1) — constant time access by index: const movie = MOVIES[0]; // Udta Teer const seat = seatRow[4]; // seat at index 4

🔗 Singly Linked List — Booking History
A singly linked list is a chain of nodes where each node holds data and a pointer (reference) to the next node. CineBook uses a custom BookingLinkedList to store booking history. Unlike arrays, linked lists support O(1) insertion at the head without shifting elements.
class BookingNode { constructor(data) { this.data = data; // booking record this.next = null; // pointer to next node } } // Memory: [data|→] → [data|→] → [data|→] → null // insertAtHead: O(1) | search: O(n) | traverse: O(n)

🔍 Linear Search — O(n)
Linear Search checks every element one by one from index 0. Best case: O(1) if found at first position. Worst case: O(n) if at last or absent. CineBook uses this for the movie search bar on the home page.
function linearSearch(arr, query) { for (let i = 0; i < arr.length; i++) { if (arr[i].title.includes(query)) { return { index: i, steps: i + 1 }; // found } } return { index: -1, found: false }; // not found }

⚡ Binary Search — O(log n)
Binary Search requires a sorted array. It repeatedly halves the search space by comparing the middle element. With n=100, binary search needs at most 7 comparisons vs. 100 for linear search. CineBook uses this to find a movie by numeric rating score on a sorted array.
// PRECONDITION: arr must be sorted ascending by key function binarySearch(arr, target, key) { let lo = 0, hi = arr.length - 1; while (lo <= hi) { const mid = Math.floor((lo + hi) / 2); if (arr[mid][key] === target) return mid; // found else if (arr[mid][key] < target) lo = mid + 1; // right half else hi = mid - 1; // left half } return -1; // not found }

🫧 Bubble Sort — O(n²)
Bubble Sort repeatedly compares adjacent pairs and swaps if out of order. After each pass, the largest unsorted element "bubbles" to the end. CineBook uses this to sort movies by rating on the home page grid.
function bubbleSort(arr, key) { for (let i = 0; i < arr.length - 1; i++) { let swapped = false; for (let j = 0; j < arr.length - 1 - i; j++) { if (arr[j][key] > arr[j+1][key]) { [arr[j], arr[j+1]] = [arr[j+1], arr[j]]; // swap swapped = true; } } if (!swapped) break; // early exit } }

🔢 Selection Sort — O(n²)
Selection Sort finds the minimum (or maximum) of the unsorted portion and places it at the front. Unlike Bubble Sort, it makes at most n-1 swaps — efficient when write operations are costly. CineBook uses this to sort theatres by price in the theatre selection screen.
function selectionSort(arr, key) { for (let i = 0; i < arr.length - 1; i++) { let minIdx = i; for (let j = i + 1; j < arr.length; j++) { if (arr[j][key] < arr[minIdx][key]) { minIdx = j; // new minimum found } } if (minIdx !== i) { [arr[i], arr[minIdx]] = [arr[minIdx], arr[i]]; // swap } } }
